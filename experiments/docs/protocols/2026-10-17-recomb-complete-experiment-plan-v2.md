# RECOMB 完整实验方案 v2：独立扩展、评价修订与重复预测

日期：2026-10-17。状态：**仅规划，未启动新实验；论文与自动跟进继续暂停。**

本文件整合本轮完整结果、上一版扩展方案和用户新提供的评审式意见。它是实验规划修订，不代表新模型已经实现。用户最新允许多次结构预测：**没有结构预测总数上限，也没有每序列只能预测一次的限制。** 本文数量用于估算工作量，不是停止计算的硬配额。

## 1. 研究主线与当前证据

任务保持不变：输入普通蛋白WT和目标缩小比例，输出满足长度要求的缩短序列。原DelePref Policy生成候选；同源天然缺失事件引导部分候选，缺口不足时由同一Policy补全；原Scorer从K8中选择；没有可用检索提案时精确退回原模型。主任务不限制删除段数。

当前结果支持“系统已跑通，部分蛋白上有检索引导收益”，尚不足以支持广泛功能保持、联合事件优势或总体最优。新实验要回答：

1. 最终缩短产物在独立蛋白、不同预算上表现怎样？
2. 是否保留酶催化身份、局部环境及binder界面，而不只保持整体形状？
3. 收益或退化来自证据、候选配额、补全、删除形态，还是Scorer选择？
4. 这些观察在有效干预、随机预测重复和第二预测器下是否稳定？
5. 为此付出了多少检索、生成、选择和预测成本？

本轮已知负结果不被“修复”掉：Terminal在当前通用面板较强；酶催化身份RAG为7/11、原模型8/11；完整RAG未明确优于简单gap。这些是观察结果。Raygun主指标不可识别、无效null/min8、低WT校准则是需要修订的评价或实验设计。

### 3.3 同源证据准备是独立工作包

WT来源审核与检索代表来源审核分开。现有通用2596个、应用957个代表的成功元数据batch全部复用；缺元数据、仅因查询物种白名单未覆盖、序列身份不符分别处理。扩大明确普通来源的正向审核，不把所有未审核来源当危险，也不把它们直接放入生成。

代表必须核对实际序列身份与来源记录。已排除对象不恢复；未能核验的证据不参与提案。检索召回、事件投影、锚点和质量规则沿用已审计语义，必要技术修订先记录，不按RAG效果调阈值。天然缺失仍只是生成证据，不是当前WT删除成功的标签。

新100/80/60队列均在生成前冻结query、数据库版本、命中、来源审核和最终profile。记录原始命中→可判定来源→合格代表→有效内部事件各级分母。旧WT的profile若改变，其旧RAG输出只能作为旧版本结果，不能混入新profile主比较；相同WT的PLM编码缓存仍可按身份复用。

## 4. 方法、生成预算与核心模型

主比较共六方法：

| 方法 | 使用的流程 | 说明 |
|---|---|---|
| DelePref不限段数 | 正式4000步Policy→精确预算候选K8→原Scorer | 当前适配基线，不冒称原≤3段原生系统复现 |
| DelePref-RAG | 原候选与同源事件提案混合/补全→K8→同一Scorer | 保留当前4+4主规则；本版不因旧结果自动改变主方法 |
| 简单gap引导 | 固定逐位置gap统计→同Policy补全→K8→同Scorer | 直接检验复杂事件是否超越简单同源信息 |
| SCISOR | 核对并优先采用官方推荐U90-L原生协议 | U90-S保留历史/效率参考；先查现有权重 |
| Raygun | 核对官方版本的原生采样与PLL选择 | 保留插替换能力，记录实际缩小率/候选数，不伪造成纯删除 |

WT是预测器校准参照，不是缩小方法。DelePref四类K8方法同权重、同候选容量；SCISOR/Raygun主表保留原生流程并标明成本，不冒称等计算量。固定20例另做SCISOR-K8共同Scorer控制；这是候选池控制，不是官方评分协议替代。

主任务不使用催化/界面标签作本方法独享保护。未来若做共享位点保护，应单列新任务、统一给可支持的所有方法相同信息，并评价保护后邻域结构；不能用“强制保留成功”证明无保护功能保持。

本版没有新增训练任务。原三槽和Scorer段数/3尺度的外推通过开发诊断明确展示。若之后决定适配训练，应先形成独立方法修订，并对无/有RAG共享同一适配模型，不能混入本版冻结原权重实验。

## 5. 先做的零新增折叠审计

### 5.1 RAG路径与候选替换

对当前44+12+11的每个条件记录：

`原始命中 → 来源/身份通过 → 可靠内部事件 → 合法直接/补全提案 → 进入K8 → 原赢家是否仍在池 → 选中来源 → 编辑序列是否改变 → 质量差值`。

当前34个相同输出分开解释为没有合格证据、没有合法提案、提案未被选中等，不统称无同源。

对负例先检查原K8赢家是否被配额移除。若移除，再检查放回后能否按同一Scorer及平局规则胜过当前赢家。只有反事实选择确实改变，才支持“配额挤出可解释此退化”；原赢家不在池中本身不构成因果证据。原赢家仍在却选择更差新提案的病例归入选择器相关诊断，但没有全池结构时不能声称检索候选整体较差。

### 5.2 影响度与碎片化

保留全体效应；逐同源/靶标组件留一重新汇总，报告留一效应范围、符号变化和最大影响组件。不是删掉大收益病例重算一个更好看的主表。

从既有输出提取段数、最长段、内部接头数、terminal比例、删除位置；与RAG−原模型的结构差配对显示。关联图只作诊断，不当因果结论。

### 5.3 统一术语与筛选时间

建立指标字典和样本流转表。已核实三种接触终点不同：全WT原生Cα接触、催化邻域Cα接触、跨链重原子界面接触。分别保留原子类型、距离、原生分母、缺失处理和实际覆盖。恢复名单按新版本记录，旧冻结及所有结果不覆盖。

## 6. 修订结构评价：共同形状与原始身份分开

### 6.1 共同结构比较层

所有六方法使用同一USalign版本和预定结构对齐模式；完整WT长度归一化，固定链身份/输入顺序，确定性平局规则。保存一次对应，用于结构映射的局部Cα几何、接触和覆盖，不为每个指标重新挑最大分的对齐。

这层回答“输出形状和局部组织是否类似WT”。不能把结构对齐位置解释成原催化残基以相同氨基酸身份被保留。结构映射未覆盖的参考关系按该指标的“未恢复”定义处理，明确是操作性结构比较，不冒称编辑来源已识别。

先用现有结构在CPU上核验恒等、删段、替换、重复片段和链对应例。旧固定对应TM及Raygun宽界保留，不能只给Raygun改指标。

### 6.2 编辑身份与固定关系层

对DelePref/RAG等有明确删除mask者，报告固定原位置的retained Cα-lDDT、全WT原生接触、共同保留关系和静态删除损失。Raygun分别报告确定对应、替换、插入和歧义；不把氨基酸替换算成催化身份保留，也不把不确定性当零分。

| 指标名称 | 固定定义与用途 |
|---|---|
| 对齐局部Cα-lDDT + 覆盖 | 统一结构映射上的局部几何；Cα局部距离阈值与参考邻域固定，不能冒称标准全原子lDDT |
| Retained Cα-lDDT | 原身份可确定的保留残基条件性局部几何；不能单独代表整个WT损伤 |
| 全WT原生接触恢复 | WT已观测Cα间<8Å、序列间隔≥3；固定原生分母。结构映射版和编辑固定对应版名称分开 |
| Full-WT TM（结构对齐） | 同一结构对齐实现、完整WT长度归一化；与旧固定对应TM分别列示 |
| 催化身份保留 | 原注释位点的真实氨基酸身份保持；不依赖折叠模型即可检查 |
| 催化邻域接触恢复 | 全WT原生Cα接触中至少一端为注释催化位点；所有注释位点纳入 |
| 催化几何误差 | 保留位点/原生邻域的几何，必须与身份保留和有效配对覆盖并报；删掉位点不能成为0误差 |
| 原生界面接触恢复/F1 | 设计链与固定partner的原生重原子接触<5Å；原生分母和链身份固定 |
| DockQ及分量 | 经变长链映射核验后报告Fnat、iRMSD、LRMSD等；工具静默裁掉删除位点时不能直接套标准总分 |

DockQ默认可寻找最佳链对应，本任务需固定生物学链角色；仅原生真实对称等价链允许预定等价置换。若工具标准分母与缩小任务不兼容，主报明确的接触/几何分量及覆盖，不给自定义总分套标准名称。

不把三个结构指标拼成一个临时加权总分，也不用置信度或WT分数归一化替代原生结构评价。

## 7. 预测协议校准与重复结构预测

### 7.1 开发WT校准

当前23应用WT先作完整构建、天然链、生物装配及必要上下文核验。旧空MSA结果保留。首轮计划两个预先定义的新增协议、各三个采样seed，约23×2×3=138次逻辑预测；实际适用构建和协议逐项登记。

新增协议优先解决标准MSA、配对链和有证据的必要上下文。相同信息对所有方法开放；不把待测原生结构模板或界面坐标用来帮助预测后再称独立验证。协议具体命令须在新作业前绑定版本、权重、MSA文件、链/辅因子构建、recycle/steps和seed；不能只写“默认参数”。

选择依据为WT参考重现、覆盖、失败、成本和是否满足适用条件，不参考任何RAG−原模型变体差值。两协议是首轮比较范围，不是预测次数上限；若发现新的构建或技术问题，先记录理由、修订协议，再做必要预测。不能为追求RAG正结果试配置。

若WT仍普遍不能重现原生界面/催化环境，应将相应结构终点标为评价能力不足，继续报告独立的序列身份结果；不复制低质量配置扩大几何结论，也不静默只保留WT高分病例。

### 7.2 正式预测与重复安排

- General主预测器保留经核验的ESMFold单次协议。确定性eval模式只换seed通常不会产生有意义的随机重复，不为凑次数重复同一确定性前向。
- 酶与binder主结构预测采用校准后统一Boltz协议。全队列一个预定seed作为主表；固定酶30、binder20子集另补两个seed，三seed单独报告。
- 第二预测器General30，六方法+WT，每个身份三个预定seed。其名单在任何新确认结构前固定，不挑主预测器正例。
- 重复预测保持最终序列、MSA、链构建、profile不变，只改变规定的随机采样因素。候选生成seed变化是另一实验因素，不能与折叠seed混合。
- 重复表先对每个WT每方法的全部预定seed求均值，再作蛋白/组件配对统计；标准差与最差seed作稳定性描述。禁止选最高原生分的一次。三个seed不把N乘三。
- 全队列单seed主表与固定子集三seed结果分开，不能对部分病例取最佳三次、其余只用一次。
- 允许必要重复、第二预测器、完整候选池和经审计技术重试；不设置总数或单序列次数硬上限。失败保留，同科学输入/seed的技术重试不作为新随机样本。

| E5 | E4内固定20例 | 原100%证据复用，50%/25%/0三档 | 嵌套证据减少、补全/回退、配对质量；不预设单调性 |
| E6 | General固定30例，20% | 六方法+WT，第二预测器各3seed | 跨模型与随机采样稳健性；WT校准同列 |
| E7 | General按输入固定12例，20% | 原/RAG完整K8池并集；原赢家保留K8控制 | 候选质量与Scorer选择分离，不反哺主输出 |
| E8 | General固定20例 | 原生六方法成本；SCISOR另K8控制 | 冷/热路径、模型调用、候选量、显存、质量—成本 |

D1是历史约束诊断，不是恢复主任务三段上限。记录受限后自然事件不可行和回退变化，不能只看结构均值。沿用旧开发预测profile以便解释单一因素；若另换profile，需给全部四臂同协议并另计缺失量。

E4–E8均嵌套General100，子集按输入及固定哈希规则选定；E4允许按是否存在可交换联合信息定义条件性队列，但不能按模型效果选。有效成员不足40就报告实际N；不把General中的无证据病例换掉，不制造伪同源。若另设外部机制队列，单列名单、WT与参照预测预算，不能藏在本矩阵计数中。

## 9. 消融具体定义与可识别性

### 9.1 两种随机控制分工

- **形态匹配控制：** 目标匹配删除量、段数、段长和terminal/internal类别，用非同源位置构造可行提案，走同一Policy补全、K8和Scorer。匹配失败和实际偏差全部记录；不把无法匹配的病例当有效干预。
- **联合关系扰动：** 在已核验事件的可交换组合内破坏同一同源背景的组合关系，尽量保留预定边际统计。记录哪些边际确实保持、联合关系是否改变；无可行扰动就不可评价，不能宣称联合优势或鲁棒性。
- 两者都必须检查事件→提案→候选池→选中输出四层是否变化。输入变化但Scorer回到原候选也是结果，不能当失败后反复随机到改变赢家。

### 9.2 无补全与去Scorer

无补全只允许天然证据本身满足预算的提案，其余回退原模型，所有失败/回退留在分母。去Scorer使用同一完整K8池、冻结Policy选择规则，不重新生成更有利池。

简单gap沿用预定逐位置统计与预算前缀规则，不能看新结果调整权重。若完整RAG最终仍与gap接近，主张收窄为“可追溯的同源引导”，不强行宣称联合机制优越。

### 9.3 稀缺梯度

按代表去冗余后固定哈希顺序构建嵌套50%/25%/0证据。报告独立代表数、事件数和与全量实际差；少量证据导致档位相同则如实标注。零证据需精确退回原模型，但这仅是回退行为验证。

### 9.4 保留原赢家的K8控制

此项放在E7已有两池并集内：先取原baseline赢家，再取当前RAG池全部检索候选，按原冻结顺序补原Policy候选至K8；去重/平局规则预先固定。只从已存在两池的候选中选，不新增或修补候选，因此不额外增加候选结构预测。

它是候选配额诊断，不默认替换主RAG规则。保持原Scorer最高候选只保证该Scorer分数不降低，不能保证真实结构更好。

E7对每个预定指标分别统计完整池分布、最好值与选中值差；没有全池结构的其他病例不报告oracle/regret。指标的池内最好值用于诊断，不用于最终产物选择或提交。

## 10. 统计、图表与结论边界

- 统计单位是蛋白/家族或抗原组件；同一结构重复、同一蛋白多预算、多抗体同靶标均不虚增独立N。
- 全体主表用预定seed；重复子集先在WT内汇总全部seed，再作组件配对bootstrap（10000次，固定seed），同时报告实际组件数。
- General主要比较RAG对原模型，两个共同主要终点为局部几何和全原生接触，TM并列报告。普通95%区间照常展示；双主要终点的联合推断另用各97.5%区间作Bonferroni校正，两者都支持时才称双指标一致增益，不据结果改选唯一主要指标。
- 酶主要终点固定为完整催化残基身份保留；催化邻域接触是关键次要终点，几何与覆盖提供解释。Binder主要终点固定为原生界面接触恢复；F1、适用DockQ分量、链内质量是次要终点。酶或binder次要指标改善不能替换其主要终点结果；三类队列不合成一个总体显著性结论。
- 每个队列报告均值差、95%区间、中位数、改善/不变/退化/未知数、全体有效分母及LOCO影响范围。修改主指标后的开发重算只能标为事后开发诊断。
- 旧General7例潜在域级训练暴露保留披露；新队列域/家族审计与推理检索来源分别登记，不混称标签泄漏。
- 各预测器单独报告；不能通过择优合并预测器分数制造更高成绩。

## 11. 复用清单、预测量与资源估算

### 11.1 优先复用

原正式Policy/Scorer与已核验基线入口、ESMC编码缓存、原生结构/注释、来源元数据、已合法构建、生成记录、预测缓存和独立解析代码全部优先复用。新SCISOR权重先在已知资产位置核对；没有的才列缺项，不重新训练现有基线。

预测缓存身份包含完整序列及链/辅因子构建、权重、MSA/模板内容、profile、seed/sample。任何一项改变即不能直接套旧预测分数。新版评价可对兼容旧结构CPU重算；不能覆盖旧评价结果。

### 11.2 计划需求，不是硬上限

以下按目标N全部达到、六方法、零缓存命中估计；同序列同profile去重会降低实际调用。重复seed对随机预测器形成不同身份，应按计划分别计算。

### 11.3 耗时与调度

约1868条ESMFold/单链诊断，约2790条Boltz正式/重复预测，首轮校准约138条。参考情景：

- 单链若平均3–10秒，约1.6–5.2 GPU小时。
- Boltz正式2790条若平均1/3/6分钟，约46.5/139.5/279 GPU小时；校准另计，长复合物可能更慢。
- 两张持续可用GPU下，预测纯运行约1–6天量级；加数据审核、MSA、基线生成、队列和技术处理，整体暂按3–9个日历日预算。不是交付保证，应以首批WT校准分长度/链数真实计时更新。
- GPU仅Slurm、允许分区，本任务最多同时两张；次数放开不等于占用他人作业或无限并发。
- 先排三个全体20%主实验及WT（1680条）；预定重复、预算、机制和第二预测器随后并行排队，优先级由问题和成本决定，不根据正负结果决定做不做。
- 报告冷启动与缓存命中分开。不能用旧混合批次时间虚构RAG加速倍数，也不能把结构评价时间算进生成时间却只给某些基线计费。
