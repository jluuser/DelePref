The checksum catalog is `benchmarks/manifest.json`, also packaged as
`delepref/assets/catalog.json`. `delepref assets list` prints it.

| Asset | Contents |
| --- | --- |

hashes remain available.

## Protocol

Scientific runners and audits remain in `recomb/`. Main General100 budget is
20%; fixed General40 uses 10/20/30/40%. Six methods are retained: DelePref,
DelePref-Base, Gap-frequency, Terminal, SCISOR-L K1 and Raygun. Native search
budgets differ where recorded; K1 is not presented as equal-K/compute.
Completion controls use 20 paired WTs. The morphology control is a post-outcome
supplement, not a separate preregistered confirmation.

Common structure-mapped contacts differ from fixed-WT identity contact fates.
The Sec6 identity example has 536 contacts: Base 137 deleted / 139
retained-unrecovered / 260 recovered; guided 150 / 58 / 328. Do not exchange
these denominators. The five-draw completion analysis is a post-outcome
sensitivity analysis: its five differences are averaged within each of 20 WTs
before the paired bootstrap (10,000 draws, seed 20261025). CPU reproduction
recalculates these intervals from the frozen per-WT differences; it does not
recalculate the structures or other archived intervals.

The Raygun strict identity values use a single deterministic exact-identity
alignment. The previously archived conservative/permissive values use a
different alignment/observability policy and remain in separate columns. The
strict point estimates are not bounds from that alternative protocol.

`paper_evidence_v2.zip` records SHA256 hashes of its source files. Research
server prefixes in JSON have been replaced with `research-source/` for
portability; those logical paths identify original inputs and do not imply that
all referenced structures have been published. The archive includes sequences
generated by Raygun and other third-party-derived data; upstream terms and
attributions remain applicable. The repository's MIT license does not
relicense them.

## Training availability

The formal training reference contains 269,915 WT sequences. The preference
corpus contains 24,386,017 pairs in 600 compressed CSV shards, with
36,013,051,774 bytes of original uncompressed pair data. The shards and
supporting selected-sequence, condition and split metadata are available in
the [public dataset](https://huggingface.co/datasets/Zhouky/DelePref-data)
under `training/`. The release manifest records each file's SHA256; its own
SHA256 is `8455b818140f8c7be73c344a8525b320c00109b24161fd782f8da22b68316e37`.
The dataset revision used for this release is `634b96176b78988961535d30effbb23970748c7e`.
The separate audit metadata provenance file has SHA256
`a6b7be44bcde9752e3d744651d060ab396cfddb1c1a9235a19a3f0b4eff74863`.
Follow the root README to download and verify the files and prepare a local
training configuration. The original candidate-query shards are not
reconstructed; compact per-shard sequence tables are derived from the frozen
conditions and selected WT manifests. See `docs/legacy_training.md` and
`recomb/provenance/` for the historical construction and training workflow.

A current UniRef download does not recreate an older snapshot byte-for-byte.
The inherited retrieval cache's exact upstream FASTA release identity is not
fully recovered. Frozen reviewed projections are included for replay. Fresh
retrieval must record database provenance and may produce different proposals.

Author-derived plots/measurements do not relicense raw databases. Historical
fixed-variant benchmarks are not new large-budget shortening assays. No
wet-lab validation is introduced by this release.
